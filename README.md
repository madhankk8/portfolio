# Enterprise Analytics Portfolio

A polished, responsive, static portfolio for Rangarajan Kachii Kadambi. Built using HTML, CSS, and JavaScript with **no build step, no paid libraries, and no backend**.

## Preview locally

Open `index.html` in a browser. For a local web server, run `python -m http.server 8000` inside this folder, then visit http://localhost:8000.

## Publish free with GitHub Pages

1. Sign in to GitHub and create a **public** repository, for example `portfolio`.
2. Open **Settings → Pages** in the repository.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, and save.
4. GitHub will display your public website URL after publishing. It will typically be `https://YOUR-USERNAME.github.io/portfolio/`.

GitHub Pages is subject to GitHub's current policies and usage limits. No custom domain is required. The site uses Google Fonts when online, with local system-font fallbacks.

## Update your website later

- **Projects and certifications:** edit `data.js`. Each item in the `projects` or `credentials` array becomes a card automatically.
- **Headline, contact links, bio, impact metrics:** edit `index.html`.
- **Visual styling:** edit `styles.css`.
- **Project modal interactions:** edit `script.js` only if you want to change behavior.
- Commit your updates to GitHub; Pages will republish the site.
